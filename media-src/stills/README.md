# Deck stills — drop exported PNGs here

Export from Figma: select the IMAGE FRAME on the slide (not the whole
slide), then Export → PNG → 2x. Selecting the frame rather than the slide
keeps the deck background and the caption out of the file.

Name each file exactly as listed below and put it in the matching folder.
Then run `npm run stills`, which converts them to webp and places them in
public/case/<slug>/. Anything missing is simply skipped, so partial drops
are fine — add what you have and run it again later.
